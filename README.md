# Избранные квартиры — Циан и Авито, карта (Санкт-Петербург)

Карта избранных объявлений на OpenStreetMap: **Циан** (круглые маркеры) и **Авито** (квадратные маркеры с той же цифрой комнат). В карточке и в галерее ссылка ведёт на нужный сайт («Циан» / «Авито»). Данные Авито — отдельный файл `data/apartments_avito.json`, при сборке склеиваются с `apartments.json` в `data/apartments.js`.

## Авито (избранное)

1. Ссылки — в `data/urls_avito.txt` (по одному URL на строку).
2. Скачивание через **Chrome + Selenium** (как у Циан), результат — `data/apartments_avito.json`, фото в `data/avito/<id>_files/`, копия HTML в `data/avito_html/<id>.html`.

```bash
pip install selenium requests beautifulsoup4
python scripts/fetch_avito_offers_selenium.py          # полный прогон
python scripts/fetch_avito_offers_selenium.py --resume # докачать только отсутствующие id
python scripts/fetch_avito_offers_selenium.py --no-images   # без загрузки фото
# Несколько Chrome параллельно (отдельный процесс на воркер; капчу так не решить — потом --workers 1):
python scripts/fetch_avito_offers_selenium.py --workers 3 --headless
```

После изменений данных (или сам скрипт в конце вызывает это):

```bash
python scripts/create_map_cian.py
```

Режим «Только видимые» / `hidden_ids.js`: в списке **и Циан** (число из `sale/flat/…`), **и Авито** (id объявления — как в данных, хвост ссылки `…_123456789`).

Сортировка **«Суммарный балл»**: один показатель 0…1 — взвешенная сумма нормализованных (по текущему списку) параметров. Веса задаются в `js/list.js` → **`COMPOSITE_WEIGHTS`**: сильнее всего **цена**, затем **комнаты**, **площадь**, ручная оценка, **цена/м²**, год, **этаж** (слабее всего). На карте обводка маркера — от красного к зелёному среди текущего списка.

**Этаж:** из `floor` берётся **доля этаж/этажность** (`4/9`, `4 из 9`). Оценка **не** «чем выше доля — тем лучше»: пик у **середины дома** (~40–50% высоты), ниже 1-й и последний этаж (чуть сильнее). Без второго числа сортировка — по `этаж / max(этажей в списке)`; цвет/суммарный балл без доли — нейтрально.

**Предустановленные оценки для гостей:** в правом верхнем углу карты чекбокс **❤ Мои оценки** (по умолчанию включён). Пока он **включён**, для квартир из данных действуют оценки из `js/rating_presets.js` (приоритетные ID — 👍, остальные — 😐), они **важнее** сохранённых в браузере в `localStorage`. Если чекбокс **выключить**, отображаются только оценки из `localStorage`. Состояние чекбокса хранится в **localStorage** (`cian_use_preset_ratings`: `1`/`0`), дополнительно дублируется в **cookie** `cian_preset_ratings` на веб-хостинге (на `file://` cookie часто не сохраняется — без localStorage чекбокс после перезагрузки сбрасывался бы).

На карте (`map_cian.html`) под фильтром комнат — четыре кнопки **👍 😐 👎 🚫**: копируют в буфер **формат для `NEWLY_HIDDEN_IDS`** — `'id','id',` для Циан и Авито сразу (оценки в `localStorage`).

Парсинг HTML живёт в `scripts/avito_offer_parse.py` (используется только Selenium-скриптом).

## Быстрый старт

1. **Парсинг избранного** (страница `data/favorite.htm`):
   ```bash
   python parse_cian_favorites.py
   ```
   Извлекаются: ссылка, превью, заголовок, **полная цена**, **полный адрес** (как на сайте), **метро** (станция + время), телефон, описание. Результат: `apartments.json`. Нужен `pip install beautifulsoup4`.

2. **Геокодирование** (координаты для OpenStreetMap):
   ```bash
   python geocode_cian.py
   ```
   Используется Nominatim (бесплатно). Для более точных координат по СПб задайте переменную окружения `YANDEX_GEO_API_KEY` и снова запустите скрипт. Нужен `pip install requests`.

3. **Генерация карты**:
   ```bash
   python create_map_cian.py
   ```
   Создаётся `map_cian.html` с картой, сайдбаром (адрес, метро, рейтинг, «Показать все фото») и слайдером по клику на превью.

3. **Открыть карту**: двойной клик по `map_cian.html` или:
   ```bash
   start map_cian.html
   ```

## Полные фото и описание по каждой квартире

- **Автоматически** (может не сработать из‑за защиты Циан):
  ```bash
  python fetch_cian_offers.py
  ```
  Скрипт качает страницы объявлений по ссылкам из `apartments.json` и пытается вытащить все фото. Затем снова запустите `create_map_cian.py`.

- **Вручную** (надёжно): для каждой из 15 квартир откройте ссылку на Циан → «Файл» → «Сохранить как» → «Веб-страница, полностью». Сохраните файлы в папку `data/offers/` с именами вида `offer_324037941.html` (число — ID из URL объявления). Затем:
  ```bash
  python parse_cian_offer_pages.py
  python create_map_cian.py
  ```
  В карте по клику на превью откроется слайдер со всеми фото и полным описанием.

## Проверка объявлений на Циан (снято / 404)

Скрипт `scripts/check_cian_offers_live.py` проходит по всем URL из `data/apartments.json` (один запрос на квартиру): **404**, снятие (**`OfferUnpublished`**), для активных объявлений — **газ** по блокам **`OfferSummaryInfoItem`** (строка «Газоснабжение»). Прогресс в консоли «текущий / всего».

```bash
python scripts/check_cian_offers_live.py
python scripts/check_cian_offers_live.py --json
python scripts/check_cian_offers_live.py --skip-gas   # без проверки газа
```

Подробнее — в `.cursor/rules/cian-operations.md`.

## Структура

- `data/favorite.htm` — сохранённая страница «Избранное» Циан (со статикой в `data/favorite_files/`).
- `data/offers/` — сюда класть сохранённые HTML страницы объявлений (по одной на квартиру).
- `apartments.json` — данные квартир (ссылка, превью, цена, адрес, координаты, фото, описание).
- `map_cian.html` — готовая карта (Leaflet + сайдбар + модальное окно-слайдер).

Картинки в сайдбаре берутся из `data/favorite_files/` (пути в JSON заданы относительно корня папки `cian`). Если открывать `map_cian.html` по протоколу `file://`, браузер может блокировать загрузку — тогда поднимите простой HTTP-сервер в папке `cian`, например: `python -m http.server 8000` и откройте `http://localhost:8000/map_cian.html`.

## Публикация на GitHub Pages

Чтобы смотреть карту по ссылке и делиться ею:

1. **Обязательно добавьте в репозиторий файл данных** (иначе на сайте будет пустой сайдбар):
   ```bash
   git add data/apartments.js
   ```
   В `.gitignore` папка `data/` игнорируется, кроме `data/apartments.js` — этот файл нужен для загрузки списка квартир на GitHub Pages. Папки `data/static_2/` и `data/static_3/` тоже в целом игнорируются, но **исключение сделано для картинок**: в репозиторий попадают только файлы `data/static_2/<ID>_files/*.jpg`, `*.jpeg` и то же для `data/static_3/`. Поэтому на GitHub Pages превью квартир из этих папок отображаются. HTML-файлы и прочее содержимое `static_2`/`static_3` в git не коммитится.

2. Закоммитьте и запушьте репозиторий (включая `map_cian.html`, `index.html`, папки `css/`, `js/`).

3. В репозитории: **Settings** → **Pages** → **Source**: **Deploy from a branch** → **Branch**: `main`, папка **/ (root)** → **Save**.

4. Через 1–2 минуты сайт будет доступен:
   - `https://<ваш-логин>.github.io/<имя-репозитория>/` или `.../map_cian.html`

Папка `data/` в `.gitignore` по умолчанию игнорируется целиком. Исключения: в репозиторий **добавляются** `data/apartments.js` и **картинки в формате .jpg/.jpeg** из папок `data/*_files/`, `data/static_2/<ID>_files/` и `data/static_3/<ID>_files/`. HTML и остальное содержимое этих папок в git не попадает. Благодаря этому на GitHub Pages отображаются превью квартир из всех static-папок без коммита всей статики.

## Добавление новых квартир (новая папка static_3, static_4, …)

Когда вы добавляете новые объявления (новый «Избранный» файл или присылаете HTML + папку со статикой с очищенными картинками):

1. **Вы:** сохраняете страницу избранного или присылаете HTML карточек; создаёте новую папку, например `data/static_4/`, и кладёте туда для каждой квартиры `<ID>.html` и `<ID>_files/` с нужными фото (лишние удалены).
2. **В проекте:** в парсер добавляется поддержка новой папки (`static_4`), в `apartments.json` — записи по новым квартирам, затем запускаются парсер и `create_map_cian.py`.
3. **Обязательно:** для каждой новой квартиры подбираются **точные координаты** (2ГИС и т.п.) и обновляются `lat`/`lon` в `apartments.json`, иначе маркер может оказаться в парке или на другом берегу.

Подробная пошаговая инструкция — в **[ADD_APARTMENTS.md](ADD_APARTMENTS.md)**.
